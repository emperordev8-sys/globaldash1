Quick-action tile icons
=======================

Put one image per tile in THIS folder. The dashboard loads it automatically.

Rules
-----
- File name = the tile label in lowercase, with spaces replaced by hyphens.
- Allowed types: .png  .jpg  .jpeg  .webp  .svg
- Square images look best (they are shown in a 40x40 rounded box, cropped to fill).
- If a file is missing, that tile keeps the drawn fallback icon (nothing breaks).
- After adding files, if the dev server is running they appear on save; if not, just reload.
